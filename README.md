# Meus Jogos 100%

Vitrine dos jogos com 100% das conquistas, em todas as plataformas.

**[Ver no ar →](https://erickkadr.github.io/meus-jogos-100/)**

![React](https://img.shields.io/badge/React-18-61dafb) ![TypeScript](https://img.shields.io/badge/TypeScript-5.6-3178c6) ![Vite](https://img.shields.io/badge/Vite-6-646cff)

## Rodar

```bash
npm install
npm run dev      # local
npm run deploy   # publica no GitHub Pages
```

## O que tem

- Design system da Steam: paleta, tipografia e a barra de conquistas azul.
- Emblema de jogo perfeito replicado em SVG, no canto inferior da capa.
- Cards platinados com borda e brilho dourado pulsante, mais um sheen diagonal.
- Entrada em stagger, barras que enchem ao entrar na viewport, contadores animados.
- Filtro (platinados / em progresso / todos) e busca.
- Responsivo e com `prefers-reduced-motion`.
